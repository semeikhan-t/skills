# neverzero

Agent skill for psychology-driven UX. Apply proven principles (smart defaults, goal gradient, reciprocity, IKEA effect, loss aversion, contrast) when building or improving user-facing UI.

## Install

```bash
npx skills add semeikhan-t/neverzero
```

or

```bash
gh skill install semeikhan-t/neverzero
```

## Usage

Use when designing onboarding flows, pricing pages, forms, signup gates, dashboards, or any interface where motivation, trust, or conversion matters. The agent should pick one or two relevant principles and apply them in logic and structure, not only in copy.
